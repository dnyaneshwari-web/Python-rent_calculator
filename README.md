# Python-rent_calculator
# 🏠 Room & Flat Expense Calculator

A simple Python project to calculate shared monthly expenses.

## Features
- Rent calculation
- Food expenses
- Electricity bill
- Charge per unit
- Number of people sharing
- Total expense
- Expense per person

## Calculation
Electricity Bill = Units × Charge per Unit

Total Expense = Rent + Food + Electricity

Expense Per Person = Total Expense ÷ Number of People
